# Registries

Registries are controlled indexes.

They make STANKOPEDIA searchable, auditable, and scalable.

## Registry Set

| Registry | Purpose |
|---|---|
| Document Registry | Master index of controlled STANKOPEDIA pages. |
| Standards Registry | Index of SEP, STD, and WF documents. |
| Wombat Registry | Index of Wombat pages and living documents. |
| Project Registry | Index of active and archived STANK projects. |
| Production Asset Register | Index of immutable approved production assets. |
| ECO Register | Index of engineering change orders. |
| Requirement Register | Index of approved requirements. |
| Decision Log Register | Index of decisions and rationale. |
| Fool's Gold Register | Evaluated and rejected options. |
| Horizon Register | Intentionally deferred ideas. |

## Rule

If a document is important enough to govern work, it is important enough to register.

# Workflows

Workflows define repeatable process execution.

## Core Workflow Families

| Workflow | Purpose |
|---|---|
| Requirements Workflow | Capture, review, and preserve requirements. |
| ECO Workflow | Change one production asset through controlled engineering review. |
| Production Promotion Workflow | Promote candidates into immutable Production Masters. |
| Decision Workflow | Record engineering decisions and rejected alternatives. |
| Documentation Workflow | Classify, register, and publish STANKOPEDIA pages. |

## Production Asset Rule

Production assets are immutable. A change requires an ECO, a candidate revision, engineering review, and promotion into a new Production Master.
